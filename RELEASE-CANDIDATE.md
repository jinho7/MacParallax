# 0.8.0 candidate

For maintainer review only. This candidate is ad-hoc signed, not Apple-notarized, and is not the public commercial download.

Changes: signed license verification, 14-day trial starting on the first successful live effect, activation/deactivation UI, optional Conversation volume response, opt-in audio onboarding, 9-language additions, cursor rendering region optimization and GPU error cleanup.

Checks: 45,771 core assertions, 16 capture/model integration scenarios, rendering pixel checks including optimized cursor comparison, packaging regressions, and 11 license/server test cases passed on one M2 Pro MacBook Pro. Provider responses in license tests are mocked; no live purchase was made. Physical sleep/wake, wider hardware compatibility and real Spaces gestures are not established by these automated results.

Before public release: Developer ID signing and notarization, merchant live-mode configuration, a test purchase and refund, working private support contact, public compatibility check.
